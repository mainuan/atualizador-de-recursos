# Atualizador de Recursos 0.2.0 RC1

Versão candidata do aplicativo Python/PyQt6, com ilustração oficial do beija-flor,
diálogos em português brasileiro, integração Plasma e PackageKit/PolicyKit.
Não é uma distribuição automática para usuários. Produção permanece desativada.

## Primeiro ensaio em VM com snapshot

Instale o `.deb` desta pré-release após conferir `SHA256SUMS`:

```bash
sudo apt install ./mainuan-atualizador-recursos_0.2.0_all.deb
mainuan-atualizador-recursos --homologacao-github
```

Na branch `main`, `packages.txt` deve conter somente:

```text
mainuan-gestao-drivers
```

`message.txt` contém a mensagem livre em português, por exemplo:

```text
Olá! O Mainuan tem novidades.
Confira quais são:
```

O aplicativo lê os dois arquivos no mesmo commit HTTPS da main e apresenta
automaticamente Gestão de Drivers 1.0. A release e o artefato são fixados por
IDs e SHA-256 já examinados; alterações posteriores não são incluídas silenciosamente.
O botão Conhecer novidades abre a release oficial correspondente.

O modo é exclusivo de VM instalada, usuário comum e abertura manual. Não altera
fontes APT, chaves, configuração normal, autostart ou histórico normal.
Não utiliza o catálogo assinado de produção nem pede chaves para este ensaio:
a confiança é HTTPS GitHub, organização/IDs oficiais e hash aprovado no aplicativo.

Antes da confirmação, verifica as dependências com python-apt e simula InstallFiles
no PackageKit. O backend precisa anunciar suporte a essa operação. Aceita somente
o aplicativo `mainuan-gestao-drivers=1.0`; alterações em outros pacotes interrompem
o teste. Dependências obrigatórias devem estar previamente satisfeitas pela VM.
Não aplica as atualizações APT pendentes. Não reinstala versão adequada já instalada.

Um `.deb` avulso não tem assinatura de repositório APT. Usa-se a autorização nativa
PolicyKit para instalação de arquivo local, que pode apresentar aviso de origem
não confiável. Não se alteram políticas do sistema, validações APT ou permissões
administrativas. Nenhuma senha é capturada pelo aplicativo.

Confira a operação, teste primeiro o cancelamento e depois autorize a instalação
na interface. **Não execute o Gestão de Drivers nem instale drivers neste ensaio.**
Confira o resultado sem abrir o gestor:

```bash
dpkg-query -W -f='${Package} ${Version} ${Architecture} ${Status}\n' mainuan-gestao-drivers
```

Esperado: versão 1.0, arquitetura all, `install ok installed`. A verificação manual
no menu do Atualizador deve reconhecer o recurso já recebido. Para desfazer a
instalação, restaure o snapshot. O estado experimental fica exclusivamente em
`~/.local/state/mainuan-recursos-homologacao-github/` (ou no XDG_STATE_HOME ativo).

Referências técnicas: [API InstallFiles](https://github.com/PackageKit/PackageKit/blob/v1.3.4/src/org.freedesktop.PackageKit.Transaction.xml),
[backend APT](https://github.com/PackageKit/PackageKit/blob/v1.3.4/backends/apt/pk-backend-apt.cpp),
[autenticação de arquivo local](https://github.com/PackageKit/PackageKit/blob/v1.3.4/backends/apt/apt-job.cpp).
