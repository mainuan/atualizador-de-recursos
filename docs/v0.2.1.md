# Atualizador de Recursos 0.2.1

Versão estável do aplicativo Python/PyQt6, homologada em VM Mainuan. Preserva a
interface clássica com o beija-flor, os diálogos em português brasileiro e a
integração nativa com KDE Plasma/Wayland e PackageKit/PolicyKit.

- Botões na ordem definitiva: **Instalar novidades**, **Conhecer novidades** e
  **Agora não**, com dimensões iguais e destaque exclusivo para instalar.
- No modo explícito `--homologacao-github`, a consulta inicial obtém metadados;
  o download começa após escolher instalar. Operações idênticas aos recursos
  anunciados dispensam uma confirmação redundante, preservando simulação,
  integridade, revalidação e autorização administrativa nativa.
- Progresso e conclusão simplificados, com sucesso informado somente após
  verificar as versões instaladas. Histórico e adiamento de 24 horas preservados.
- Detalhes técnicos continuam acessíveis pelo menu. Advertências nativas de
  confiança do PackageKit/PolicyKit são preservadas, sem alteração de políticas.

O pacote declara `Architecture: all`, sem executáveis ELF ou bibliotecas nativas
incorporadas. Utiliza Python/Qt/PyQt6 da distribuição e não introduz requisito
x86-64-v2/v3/v4. A verificação do conjunto de dependências em CPU x86-64-v1 real
permanece pendente; a auditoria do pacote próprio foi estática.

Validação anterior à publicação: 181 testes automatizados aprovados, Lintian sem
diagnósticos, interface em Wayland e instalação/remoção/reinstalação em raiz
descartável. O funcionamento real de instalação foi aprovado pelo responsável
em VM Mainuan com snapshot.

## Arquivos publicados

O `.deb` anexado é exatamente o artefato final homologado em
`dist/final-0.2.1/`, sem recompilação ou substituição para a release:

```text
ba6d66c08d53d40d94bfc31da6110bb99fede20426796e68cf07607f0a16b0a2  mainuan-atualizador-recursos_0.2.1_all.deb
```

Uma cópia desses dois arquivos está em `releases/v0.2.1/` para permitir que o
GitHub Actions publique os bytes aprovados, separadamente do pacote reconstruído
pela CI para validação. Somente a tag autorizada `v0.2.1`, após o job de testes e
construção passar, pode executar essa publicação.

Após baixar o pacote e seu checksum para o mesmo diretório:

```bash
sha256sum -c mainuan-atualizador-recursos_0.2.1_all.deb.sha256
sudo apt install ./mainuan-atualizador-recursos_0.2.1_all.deb
```

**A infraestrutura de produção continua desativada.** Esta release não habilita
catálogo, chaves oficiais, repositório APT ou distribuição automática de novidades.
`packages.txt` e `message.txt` não foram alterados. A pré-release `v0.2.0-rc1` foi
preservada. O ensaio GitHub continua dependendo de ativação manual explícita:

```bash
mainuan-atualizador-recursos --homologacao-github
```

Esse ensaio permite somente o aplicativo Gestão de Drivers 1.0 já aprovado;
não instala drivers de hardware nem aplica atualizações gerais pendentes.
