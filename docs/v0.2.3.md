# Atualizador de Recursos 0.2.3

Correção final de compatibilidade, preservando o fluxo 0.2.2 aprovado pelo
responsável em duas VMs Mainuan: instalação de uma novidade e reconhecimento de
programa já instalado, sem reinstalação.

A identificação e a compatibilidade usam uma política única em `session.py`:

| Identificação | Resultado |
| --- | --- |
| ubuntu / 26.04 | Compatível com a base suportada |
| ubuntu / 2026 | Compatível, identificação legada Mainuan |
| mainuan / 26.04 ou 2026 | Compatível, identificações legadas |
| mainuan / 2027.1, apresentação RC1 ou final | Compatível, base Kubuntu 26.04 |
| ubuntu / 2027.1, 24.04, 26.10 ou outras versões | Bloqueado |
| Outros IDs/versões não previstos ou base explicitamente contraditória | Bloqueado |

`system_identity()` preserva ID/VERSION_ID comerciais e informa separadamente a
base conhecida `ubuntu/26.04`. VERSION e PRETTY_NAME não decidem compatibilidade:
a apresentação RC1/final não exige matrizes diferentes. O contrato esperado para
Mainuan 2027.1 é base resolute; UBUNTU_CODENAME diferente, quando declarado, bloqueia.
Sem esse campo, o par explícito mainuan/2027.1 representa o contrato da futura ISO,
que ainda precisa ser conferido no rootfs real. Não é detecção independente da base.

Consulta, filtros das novidades, histórico/cache e modo legado compartilham essa
política. A seleção valida os pares completos, sem permitir combinações extras por
produto cartesiano das listas. Cache 0.2.2 mantém edições, pins, histórico e
arquitetura, atualizando somente os filtros de plataformas conhecidas do canal.
Sessões Live ou desconhecidas continuam sem consulta/instalação pelo aplicativo.

Interface, ordem dos botões, packages.txt/message.txt, download após o clique,
SHA-256, PackageKit/PolicyKit, reconhecimento de versões instaladas, progresso,
histórico, adiamento e autostart foram preservados. Nada é instalado automaticamente.
O publicador antigo de catálogo/APT permanece desativado. HTTPS/SHA-256 não são uma
assinatura APT, e advertências nativas de segurança continuam preservadas.

O pacote permanece `Architecture: all`, sem ELF/bibliotecas nativas incorporados
nem compilação nativa. Não acrescenta requisitos próprios de ISA acima de x86-64-v1;
Qt/PyQt6 continuam sendo fornecidos pela distribuição. Não foi feito teste em CPU
v1 real nem em uma ISO Mainuan 2027.1, que ainda não está disponível.

Os testes de compatibilidade 2027.1 usam identificadores simulados, incluindo RC1,
final, consulta/janela normal e automática, legado, cache, sistema incompatível e
Live. A instalação real aprovada pelo usuário corresponde à versão 0.2.2.

Validação da versão: 212 testes automatizados aprovados; pacote Debian verificado
com Lintian e auditoria de arquitetura. Interface exercitada localmente em Wayland
e ciclo Debian em raiz descartável, sem instalação no sistema principal.

Após baixar os anexos para o mesmo diretório:

```bash
sha256sum -c SHA256SUMS
sudo apt install ./mainuan-atualizador-recursos_0.2.3_all.deb
mainuan-atualizador-recursos
```

Pronto para inclusão na futura ISO Mainuan 2027.1 RC1 após a validação automatizada
da release, ressalvada a conferência dos identificadores e da base no rootfs real.
O pacote mainuan-release e a migração RC1 → final continuam somente planejados.
