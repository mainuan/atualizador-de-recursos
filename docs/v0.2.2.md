# Atualizador de Recursos 0.2.2

O GitHub é o canal padrão. Basta executar:

```bash
mainuan-atualizador-recursos
```

Lê `packages.txt` e `message.txt` do mesmo commit oficial e descobre releases
estáveis com Debian compatível dos repositórios Mainuan listados. Suporta vários
programas e novas versões sem recompilar. Não exige `--homologacao-github`, VM,
chaves de catálogo, GitHub Apps ou repositório APT adicional.

Preserva interface aprovada, download após o clique, SHA-256, metadados internos,
simulação/revalidação, PackageKit/PolicyKit, progresso e conclusão verificada.
Pacotes recebidos não são reinstalados. Alterações não anunciadas são bloqueadas.
Histórico, cache offline e adiamento permanecem. `--check` usa o mesmo canal,
sem consultas Live ou instalação automática.

HTTPS e o SHA-256 do GitHub não equivalem à assinatura APT. Advertências nativas
de segurança permanecem. O publicador antigo de catálogo/APT está desativado e
não é acionado ao editar os dois arquivos.

Pacote `Architecture: all`, sem ELF/bibliotecas nativas incorporados ou compilação
nativa. Não introduz requisito próprio de ISA acima de x86-64-v1. Dependências
Qt/PyQt6 vêm da distribuição; teste em CPU v1 real não foi realizado.

Validação local: 200 testes automatizados aprovados, incluindo as entradas sem
parâmetros e `--check`, múltiplos programas, novas releases, rede/cache, integridade
e efeitos simulados. Consulta real ao GitHub pela entrada normal em Wayland,
sem baixar pacotes; interface demo em 640×480 e ciclo Debian em raiz descartável.
Lintian sem diagnósticos. Nenhum pacote foi instalado no sistema principal.

Após baixar os dois anexos para o mesmo diretório:

```bash
sha256sum -c SHA256SUMS
sudo apt install ./mainuan-atualizador-recursos_0.2.2_all.deb
mainuan-atualizador-recursos
```

Veja [como publicar por dois arquivos](canal-github.md). A instalação real aprovada
anteriormente corresponde à versão 0.2.1; esta integração 0.2.2 está preparada para
o teste prático final na VM, sem alegar uma instalação real não realizada.
